# Student Journey

## 1. Discovery (Pre-Login)
The student is exploring options. The UI is rich, visually engaging, and focuses on answering "Can I afford this?" and "Am I eligible?".
**Key Actions**: Browsing destinations, using the AI Advisor, reading success stories.
**UX Principle**: Low friction. We do not demand an account until the user wants to save something (Shortlist) or apply.

## 2. Onboarding (First Login)
The student has submitted an enquiry and set up their account.
**UI Goal**: Build trust and clearly outline the roadmap.
**Components**: Progress stepper (Profile -> Documents -> Shortlist -> Apply). Empty states should be encouraging, explaining *why* the data is needed.

## 3. Preparation (Profile & Documents)
The student is filling out their academic history and uploading documents.
**UX Principle**: Validation is critical. Forms must auto-save or clearly indicate required fields. Document uploads must show progress bars and success toasts.

## 4. Application (The Core Loop)
The student tracks their university applications.
**UI Goal**: Transparency. Applications are complex; the UI must break them down into simple stages (Draft, Submitted, Conditional Offer, Unconditional Offer).
**Mobile Priority**: Students check status updates frequently on mobile. The application tracker must be perfectly optimized for thumb scrolling and quick visual parsing.

## 5. Visa & Pre-Departure
The final stages. High stress for the student.
**UX Principle**: Reassurance. Clear checklists of required actions. Prominent "Message Counselor" floating action button (FAB) on mobile.
